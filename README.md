# Image fetcher for GitHub Pages

1. Put this folder's files in the root of your repo.
2. Edit `images.json` with real image URLs (Wikimedia Commons is a good, properly licensed source) and credits.
3. Push. The "Fetch images" workflow downloads them into `/images` (or run it manually from the Actions tab).
4. Use them in your site: `<img src="images/grapes-red.jpg" alt="Red grapes">`
5. Turn on GitHub Pages: Settings > Pages > deploy from branch.

Only use images you have the right to use, and keep the credits.
